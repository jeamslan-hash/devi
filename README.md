# Jesyon Abone Dlo (Python + SQLite)

Sa se yon ti aplikasyon desktop (Tkinter) pou:
- Anrejistre abone dlo
- Chèche, modifye, efase abone
- Sere done yo nan `SQLite` (`abone_dlo.db`)

## Kondisyon
- Python 3.9+ (tkinter ak sqlite3 vini default nan pifò enstalasyon Python)

## Kijan pou lanse
```bash
python app.py
```

## Sa ki nan fòm nan
- Non
- Siyati
- Telefòn
- Adrès
- Nimewo kontè (inik)
- Dat enskripsyon
- Balans
- Estati

## Remak sou done GPT "gab"
Mwen pa ka pran done dirèkteman nan lòt GPT/platfòm depi isit la. Men ou ka:
1. Ekspòte done "gab" yo an CSV/Excel
2. Antre yo manyèlman nan fòm nan, oswa
3. Mwen ka ede w ajoute yon bouton **Import CSV** nan pwochen etap la.

## Pou itilize sou nenpòt machin
- Enstale Python
- Kopye `app.py` sou machin nan
- Lanse `python app.py`
- Fichye bazdone `abone_dlo.db` ap kreye otomatikman nan menm katab la
